# Сервис по симуляции оплаты услуг ЖКХ (protobuf файлы)

protobuf файлы для [сервиса по симуляции оплаты услуг ЖКХ](https://github.com/iskanye/utilities-payment)

## Структура

### Пакет auth

* Функция Register - Регистрирует пользователя в системе
* Функция Login - Передаёт пользователю его токен для взаимодействия с другими сервисами
* Функция Users - Получает список всех пользователей, кроме админов

### Пакет billing

* Функция AddBill - Добавляет счёт в базу данных
* Функция GetBills - Получает все платежи пользователя по его ID
* Функция PayBill - Оплачивает счёт (Удаляет его из базы данных, предварительно платёж счёт надо обработать через пакет payment)

### Пакет payment

* Функция ProcessPayment - Обрабатывает платёж, возвращает статус платежа (В процессе, успешно или ошибка)
